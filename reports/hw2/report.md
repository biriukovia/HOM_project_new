## 1. Задача и место верификатора

[порождено: Codex]
В проекте HOM совпадения фотонов описываются моделью C(x)=A[1−V K(x−x₀)],
где K — свёртка exp(−|u|/L) с нормированной гауссовой плотностью ширины s.
Проверяется реализация ядра, оболочки модели и перевода сантиметров в пикосекунды
в [hom_models.py](../../src/hom_models.py). Ошибка единиц непосредственно меняет
интерпретацию временного масштаба; ошибка ядра меняет предсказанную форму провала.
Новый фит, бутстреп физических параметров и новые измерения не выполнялись.

## 3. Верификатор

[порождено: Codex]
[Точка входа](../../checks/hw2/verify.py), [реализация](../../checks/hw2/engine.py).
Генеративные тесты используют NumPy RNG; Hypothesis и автоматическое уменьшение
контрпримеров не применяются. Каждый из восьми пунктов проверен на 640 наборах.
Независимый эталон интегрирует exp(−|u−sz|/L) exp(−z²/2)/√(2π) по z∈[−12,12],
с точкой излома u/s. Отброшенная масса нормального хвоста <4·10⁻³³.
Погрешность квадратуры контролируется; NaN, Inf и ошибки интегрирования
не исключаются из среднего, а приводят к отказу.

[порождено: Codex]
| ID | Свойство | Основание | Допуск | Максимальная метрика |
|---|---|---|---|---|
| P1 | Конечность и 0 ≤ K ≤ 1 | Усреднение ограниченной функции по плотности | 1e-12 | 0 |
| P2 | Чётность | Чётность экспоненты и гауссовой плотности | 1e-12 | 0 |
| P3 | Масштабная инвариантность | Одновременная смена единиц u, L, s | 1e-10 | 3.885780586e-16 |
| P4 | Невозрастание при u ≥ 0 | Симметричные унимодальные ядра; сетка из 65 точек | 1e-12 | 0 |
| P5 | Совпадение с независимой свёрткой | Определение exp*gauss через интеграл | 1e-9 | 7.494005416e-16 |
| P6 | Предел s/L → 0 | Липшицева оценка с E|Z| = √(2/π) | √(2/π)·1e-6 + 1e-10 | 7.978840608e-07 |
| P7 | A(1−V) ≤ C ≤ A; V=0 ⇒ C=A | Форма модели при 0 ≤ V,K ≤ 1 | 1e-10 | 0 |
| P8 | Однопроходный перевод см ↔ пс | Соглашение проекта и независимые константы c,n | rtol=1e-12, atol=1e-10 | 8.247360161e-06 |

[порождено: Codex]
P8 сообщает отношение ошибки к допуску atol+rtol·|эталон|; оно должно быть ≤1.
Для остальных пунктов показана абсолютная ошибка либо положительное нарушение
неравенства. Максимальное расхождение ядра с квадратурой в P5 —
7.49401e-16; вердикт полного прогона — **PASS**, код **0**.
Конечная сетка и случайные входы не заменяют математического доказательства.

## 8. Ограничения

[порождено: Codex]
- Это проверка реализации на ограниченных наборах, не доказательство для всех входов.
- Не проверяются глобальность минимума фита, экспериментальные ошибки, g²(0),
  истинность механизма джиттера и независимое значение времени жизни.
- Область тестов ограничена METHOD.md; нулевая ширина и произвольно большие s/L не заявлены.
- Квадратура и формула используют float64 и SciPy. Их согласие не исключает общих
  ошибок окружения; оценка ошибки quad не является формальным сертификатом.
- t-интервал при десяти повторах приближённый; sign-flip тест предполагает симметрию
  парных разностей при нулевой гипотезе. Наборы seed фиксированы заранее.
- Статистическая неопределённость относится к генератору тестовых входов, а не к
  экспериментальным параметрам. Базовая линия заведомо не учитывает конечный джиттер.
- Официальный check_week6.py пропущен по разрешению пользователя от 05.11.2026;
  успешная официальная проверка не заявляется. Lean не использовался (выбрано направление B).
- Личная приёмка отчёта и отправка формы выполняются пользователем.
