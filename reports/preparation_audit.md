Дата: 19.10.2026. Исполнитель: ассистент ChatGPT/Codex в этой беседе.
Это запись фактической подготовки, не журнал старых сессий пользователя.

## Исходное состояние

- Один коммит `2d40fe9` от 13.10.2026, сообщение «Готовый проект»; remote не настроен.
- `AGENT.md` задавал исследовательскую цель без конечной команды приёмки и бюджета.
- В журнале две записи. Сведения о `/status`, сравнении ±AGENTS, конкретном режиме
  запуска и личной приёмке из архива восстановить нельзя.
- Четыре отслеживаемых файла имели только различия CRLF/LF: данные и числовые
  результаты совпадают с коммитом. Научные данные не повреждены.
- Есть полные расчёты, bootstrap, графики и статья; нет готовых артефактов недель 3–5.

## Почему полный запуск дорог

`fit_hom.py` выполняет 3000 обычных и 1000 блочных бутстрэп-подгонок. Для каждой
из 4000 реплик `derived()` строит сетку из 200001 точки ради FWHM — порядка
800 миллионов вычислений ядра. `verify_fit.py` содержит более тысячи других
подгонок и глобальные оптимизации. `verify_model.py` при шаге 0.5 пс создаёт
матрицы 3840×3840, несколько больших массивов одновременно.

Вычисления Python сами по себе не расходуют LLM-токены. Расход растёт, когда
агент многократно запускает их, читает вывод, обсуждает исправления и продолжает
большую задачу. Точный прошлый расход по этому архиву неизвестен.

## Замечания вне текущей учебной задачи

- Старые verify-скрипты печатают отчёты, но не дают содержательного ненулевого кода
  при неверных числах. Добавлена отдельная конечная проверка для учебного опыта.
- Формула Laplace имеет устранимую особенность при L=lr; exp*gauss численно
  неустойчива при экстремальном s/L. Найденный основной fit вне этих областей.
- Асимметричная пробная модель имеет скачок в центре при разных L слева и справа;
  её не следует считать общей физической проверкой асимметрии без доработки.
- Научная статья требует отдельной редакторской проверки: модельные выводы
  условны, альтернативные хорошие фиты не доказывают уникальности механизма;
  PDF содержит неразрешённые ссылки библиографии. На подготовку курса это не влияет.

Исходные научные функции не изменены, кроме поясняющих docstring двух функций.
Большие расчёты, API-запросы учебного агента и внешнего поиска здесь не запускались.
