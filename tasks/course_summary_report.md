# course_summary_report

## Запрос пользователя
Подготовить итоговый отчет `reports/course_summary.md` до 500 слов.

## Готово, когда
Создан файл `reports/course_summary.md`, который содержит:
- Проверенные данные
- Описание модели
- Воспроизведенные числа
- Команду независимой проверки
- Ограничения физической интерпретации
- Связь с графом (заметка типа Отчёт)

## Не входит
- Изменение онтологии или проверок
- Перезапуск fit
- Изменение научной статьи

## Итог
Создан отчет `reports/course_summary.md` и связующая заметка `notes/course_summary_note.md`.
