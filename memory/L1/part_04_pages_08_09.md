# Часть 4. Приложение A: корреляционный формализм (PDF, с. 8–9)

Модель источника предполагает одинаковые состояния в последовательных импульсах, период $\tau_p$ значительно больше времени жизни возбуждения, одинаковую поляризацию и одномодовое распространение [PDF, с. 8]. Временная плотность $\rho(t_1,t_2)$ ограничена одним периодом; активный демультиплексор с ячейкой Поккельса и задержкой синхронизирует соседние фотоны в двух входах [PDF, с. 8]. Корреляцию выходов получают преобразованием операторов через неунитарную подматрицу $M'$ [PDF, с. 8–9]. Общая формула учитывает многофотонную компоненту $G^{(2)}$, интенсивность $I(t)$, корреляцию первого порядка $G^{(1)}$, двухфотонную когерентность $C^{(2)}$ и члены $B_0$ [PDF, с. 9, (A5)–(A6)]. Неразличимость определена как $I=\mu^{-2}\iint|G^{(1)}(t_1,t_2)|^2\,dt_1dt_2$, где $\mu=\int I(t)\,dt$ [PDF, с. 9, (A7)]. Для разделённых импульсов $|t_2-t_1|>\tau_p$ применяется некоррелированность состояний; интегрирование по временам и нормировка на $\mu^2$ дают площади пиков [PDF, с. 9]. Следовательно, простое отношение площадей требует явной проверки допущений о состоянии источника [PDF, с. 9–10].
