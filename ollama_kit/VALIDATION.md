# Техническая проверка комплекта

Проверено 19.10.2026 в среде подготовки (Linux, Python 3.12).

- Синтаксис Python-файлов и всех 46 кодовых ячеек двух ноутбуков проверен.
- Формат обоих ноутбуков проверен nbformat; outputs пустые, execution_count = null.
- Запускатель проверен с подменёнными процессом Goose и HTTP Ollama: аргументы,
  рабочая папка, режим approve, отдельный журнал, экспорт, сохранение неподтверждённого
  статуса результата, dry-run без новой сессии и запрет молчаливого чтения всей статьи
  в слишком малом локальном контексте.
- prepare_workspaces.py проверен на временном проекте: пять отдельных папок,
  реальные исходные Git-коммиты с тестовым автором только во временных fixtures,
  отсутствие договора в нужном варианте и точечное удаление соглашения во втором опыте.
- audit_graph.py принимает согласованный тестовый граф и отвергает ссылку на
  отсутствующий файл. На незаполненном HOM-графе сообщает недостающие объекты и классы.
- Исследовательский MCP реально зарегистрировал пять инструментов через mcp 1.30.0.
  Вызов через MCP с запрещённым запросом изменения был отклонён и записан в журнал;
  запрос к Wikidata при этой проверке не отправлялся.
- Ячейки подключения и ask проверены с OpenAI SDK 3.35.1 и подменённым HTTP-транспортом:
  передаётся имя Ollama, а не URI Яндекса; сохраняются ответ и usage. Клиент localhost
  не зависит от системных proxy-переменных. Формат проверен nbformat 5.11.1.

Ограничения: установленный у пользователя Goose, его Windows-shell, GPU, облачный
аккаунт/квоты и реальные ответы OpenAlex/Wikidata здесь не проверялись.
Интеграционная проверка пользователя начинается с smoke и mcp-test. Подменённые
ответы технических тестов не включены в сдаваемые журналы и не считаются домашней работой.

Оригинальный HOM-проект не изменён; комплект добавляется отдельной папкой.
