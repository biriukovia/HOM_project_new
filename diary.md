# Журнал проекта "Провал манделя"

## 2026-09-30 — анализ провала Хонга–Оу–Манделя и статья

**Запрос.** Выполнить цель из AGENT.md: построить физическую модель формы провала по `data/data.txt`, аппроксимировать, извлечь параметры источника, написать статью по шаблону ICML в `paper/`.

**Что сделано.**
- `src/hom_models.py` — модели провала вида C(x) = A[1 − V·K(x − x0)]: экспонента (двухуровневый излучатель с дефазировкой, J = (T2/2T1)·e^{−|τ|/T1}), экспонента ⊗ гауссов джиттер момента излучения (основная модель, замкнутая формула через erfc), экспонента ⊗ лапласов джиттер (экспоненциальная накачка), когерентный вариант (волновой пакет, сформированный гауссовым импульсом), а также гауссова, лоренцева и асимметричная формы для сравнения.
- `src/fit_hom.py` — МНК-аппроксимация всех моделей, AICc/BIC, тест серий, Дурбин–Уотсон, Шапиро–Уилк; бутстрэп (3000 по остаткам + 1000 блочных), производные величины; рисунки и таблицы в `results/`.
- `src/verify_model.py` — независимая численная проверка ядра (прямое двойное интегрирование двухвременной когерентности на сетке).
- `src/verify_fit.py` — глобальный оптимизатор, injection–recovery, мощность различения Гаусс/Лаплас, 10-кратная кросс-валидация, подвыборки, оценка V0 почти без модели, проверка A = 1/2.
- `src/model_systematics.py` — разброс ключевых величин между допустимыми моделями.
- `paper/hom_dip.tex` → `paper/hom_dip.pdf` (7 стр., шаблон ICML 2026, опция preprint).

**Результат** (однопроходная схема, τ = Δx/c):
- Лучшие модели: экспонента ⊗ гауссов джиттер и её когерентный вариант (σ остатков 1.69e-3 при безмодельной оценке шума 1.45e-3, остатки случайны). Чистая экспонента, лоренциан и гаусс отвергаются (ΔAICc > 300); лапласов джиттер хуже (ΔAICc = 8.6).
- V0 (видность при нулевой задержке) = 0.8321 ± 0.0012 (стат.) ± 0.004 (модель); V_int (без джиттера) = 0.9196 ± 0.0015.
- T1 = 130.8 ± 0.7 ± 1.9 пс; джиттер момента излучения σ1 = 11.9 ± 0.3 пс на фотон; x0 = 1.366 ± 0.004 см; ширина провала на полувысоте 6.28 см (210 пс).
- T2 ≥ 218 пс (через V0) или 241 пс (через V_int); ширина линии ≤ 1.46 ГГц (6.0 мкэВ), не более чем в 1.2 раза выше фурье-предела 1.22 ГГц; T2* ≥ 1.3 нс; длина когерентности cT2 ≈ 6.5–7.2 см.
- Асимптота A = 0.523 ≠ 0.5: либо нормировка произвольная, либо джиттер когерентный (V_int превышает предел 2RT/(R²+T²) = 0.912 на 4.2σ, если считать нормировку абсолютной).

**Способ проверки.**
- Ядро: `python src/verify_model.py 1` и `... 0.5` → `results/verify_model_dt*.txt` (отличие от аналитики 2.5e-3 → 1.3e-3, линейная сходимость по шагу; замкнутая формула против квадратуры 3e-16).
- Аппроксимация: `python src/verify_fit.py` → `results/verify_fit.txt` (DE совпадает с LM до 4e-8; смещение < 0.1σ, покрытие 65–69 %; CV и AICc дают одинаковый порядок моделей; подвыборки согласуются в пределах 1σ; V0 почти без модели = 0.831).
- Основные числа: `python src/fit_hom.py` → `results/fit_results.json`, `results/physical_parameters.csv`, `results/model_comparison.csv`.
- Независимо в эксперименте: время-разрешённое измерение T1, g2(0) и скан с ортогональными поляризациями (даст A и нормировку).
