# HOM: продолжение домашней работы AI4Science

Архив подготовлен 19.10.2026 по предоставленному проекту.
Подготовка сохранена отдельным коммитом ассистента; следующий git diff покажет
изменения вашего нового запуска, а не всю эту подготовку. Научные данные,
прежние результаты и история исходного git сохранены. Это рабочая подготовка,
а не заявление о выполнении всех упражнений курса.

## Начать здесь

Распакуйте архив в отдельную папку. Откройте терминал в `HOM_project_new`.
Используйте то Python-окружение, в котором уже работал ваш проект.

```bash
python -m pip install -r requirements-course.txt
python checks/check_selftest.py
ai4science doctor
ai4science --no-lean --mode approve
```

`check_selftest.py` создаёт только временные файлы. Он должен принять правильный
результат и отвергнуть три повреждённых. Поэтому отдельные строки `FAIL` внутри
этого опыта ожидаемы; итог — `SELFTEST PASS`, общий код завершения 0.

В сессии агента вставьте содержимое `prompts/01_fit.txt`. После ответа выполните
`/status` и сохраните его вместе с результатом. Если квота пока исчерпана,
работайте с памятью и локальным поисковым ноутбуком; не повторяйте запрос по кругу.

После реального прогона самостоятельно выполните:

```bash
python checks/check.py
git diff
git status --short
```

Ожидается примерно `n=130`, `V0=0.832109`, `T1_ps=130.8119` в заданной модели.
До первого запуска агента файла `results/course_fit.json` нет; обычная проверка
поэтому выдаст FAIL. Это ожидаемое состояние, не неисправность установки.

В `diary.md` добавьте собственный итог проверки и только после этого делайте
коммит. Для кода завершения: PowerShell — `$LASTEXITCODE`, Bash/WSL — `echo $?`.
Команды `python` при необходимости замените на `python3`.

## Что подготовлено

- Новый `AGENTS.md` с маленькой целью; старый файл сохранён в `docs/`.
- Быстрый fit и независимая конечная проверка с отрицательными контролями.
- `INDEX.md`, `STATUS.md`, черновик онтологии и запросы для отдельных сессий.
- Каскад L1 → L2 → L3 по выбранной статье, выполненный в отдельных контекстах.
  Кандидаты для сверки не помечены как проверенные человеком.
- Два настроенных, но не выполненных здесь ноутбука. Старые демонстрационные
  outputs очищены, чтобы не выглядеть как ваши новые результаты.
- `docs/HOMEWORK_PLAN.md` с полной очередью упражнений и критериями готовности.

## Перед публикацией

Ключи и `.env` не включать. Локальные копии корректуры в `paper_memory/` и
`literature/NG10488.pdf` исключены из новых git-добавлений; в архиве они сохранены
для работы. Исходные уже отслеживаемые файлы `.gitignore` автоматически не убирает.
Remote в полученном проекте отсутствовал. После создания собственного удалённого
репозитория настройте его адрес и загрузите ветку; проверьте доступ проверяющего.

Не запускать весь `src/fit_hom.py` ради оформления домашнего задания: там 4000
бутстрэп-подгонок и вычисление ширины на большой сетке для каждой реплики.
`cascade.sh` тоже не перезапускать поверх проверенной памяти: он перезаписывает L2/L3.
